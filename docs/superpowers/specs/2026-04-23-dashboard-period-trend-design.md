# 草莓私帐看板月季年趋势设计

## 当前状态

本设计在 2026-04-23 之后已落地并继续演进。当前应用顶部范围选择为 `日 / 月 / 季 / 年`，其中 `日` 和 `月` 都使用月份值选择；`季` 使用自然季度；`年` 使用自然年。

2026-04-30 的实现补充了日趋势口径：收入、支出、结余继续只统计已确认流水，待确认金额单独显示为 `待确认` 线，用来区分没有数据和已有数据但未确认。下面的原始设计保留为历史记录；如与 [架构说明](../../architecture.md) 冲突，以架构说明和代码为准。

## 背景

当前应用已经导入 2026 年 1 月到 4 月的全年私帐明细，原有看板仍以单月口径展示。用户希望进一步看到年视图和季度视图，优先解决“全年走势一眼看清”的问题。

本设计不新增独立年度页面，而是在现有看板中增加 `月 / 季 / 年` 时间粒度切换，延续当前工作台入口。

## 已确认决策

- 布局采用 `B 趋势驾驶舱`。
- 初始时间粒度：`月 / 季 / 年`；后续实现已扩展为 `日 / 月 / 季 / 年`。
- `季` 使用自然季度，例如 `2026 Q1`、`2026 Q2`。
- `年` 使用自然年，例如 `2026`。
- `季 / 年` 首屏优先展示按月趋势。
- 顶部四张指标卡：
  - `收入`
  - `支出`
  - `结余`
  - `待确认`
- 主图初始设计展示三条趋势：
  - `收入`
  - `支出`
  - `结余`
- `结余 = 已确认收入 - 已确认支出`，允许为负数。
- 当前日趋势会额外展示 `待确认` 线；季和年仍以正式趋势扫读为主。
- 账户余额仍展示当前余额，不做历史回溯。

## 页面结构

### 顶部工具区

顶部保留现有看板标题和操作按钮，新增时间粒度切换：

- `月`
- `季`
- `年`

时间选择器随粒度变化：

- 月模式：显示 `YYYY-MM`，例如 `2026-04`。
- 季模式：显示自然季度，例如 `2026 Q2`。
- 年模式：显示年份，例如 `2026`。

### 趋势驾驶舱布局

主内容采用左右结构：

- 左侧：大面积 `按月趋势` 图。
- 右侧：四张竖排或 2x2 指标卡。
- 下方：三个摘要块：
  - `账户余额概览`
  - `近期待处理`
  - `流水摘要`

月模式可以保持现有工作台密度；季/年模式启用趋势驾驶舱布局。

## 统计口径

### 范围计算

- 月：所选自然月。
- 季：所选自然季度。
- 年：所选自然年。

所有统计均根据 `Transaction.occurred_on` 的日期前缀筛选。

### 顶部卡片

- `收入`：所选范围内 `status = 已确认` 且 `transaction_type = 收入` 的金额合计。
- `支出`：所选范围内 `status = 已确认` 且 `transaction_type = 支出` 的金额合计。
- `结余`：`收入 - 支出`。
- `待确认`：所选范围内 `status != 已确认` 的收入和支出金额绝对值合计。

### 趋势图

趋势图按月份聚合。

- 月模式：可以展示当月每日趋势，或者首版先保留现有月度工作台，不强制画图。
- 季模式：展示季度内 3 个月。
- 年模式：展示全年 12 个月。

趋势图只统计已确认流水：

- 收入线：已确认收入。
- 支出线：已确认支出。
- 结余线：已确认收入减已确认支出。

待确认金额不画进趋势图，避免污染正式趋势。

### 账户余额

账户余额仍使用当前既有口径：

```text
最后一条已确认余额快照 + 之后已确认流水净变化
```

账户余额不按历史月、季、年回溯。若源文件账户列为空，不自动创建虚构账户余额。

## 数据与代码边界

建议增加一个纯计算层函数，避免 UI 直接拼统计：

- `PeriodGranularity`
  - `month`
  - `quarter`
  - `year`
- `PeriodSelection`
  - `granularity`
  - `year`
  - `month`
  - `quarter`
- `build_period_summary(selection, transactions)`
- `build_monthly_trend(selection, transactions)`

UI 只负责：

- 读取当前选择。
- 调用计算函数。
- 渲染指标卡、趋势数据和表格。

## UI 行为

- 默认打开仍显示当前月份。
- 用户切换到 `季` 后，默认选择当前日期所在自然季度。
- 用户切换到 `年` 后，默认选择当前年份。
- 切换粒度或时间选择后，所有指标即时刷新。
- `待确认` 点击后，后续可以筛选流水列表到待确认项；首版可只展示数字。

## 错误与空状态

- 所选范围内没有流水时：
  - 四张卡片显示 `¥0.00`。
  - 趋势图显示空状态文案：`当前范围暂无已确认流水`。
- 有待确认但没有已确认流水时：
  - 趋势图仍为空。
  - `待确认` 卡片显示金额。
- 年份或季度超出数据范围时，不自动编造数据。

## 测试计划

### 计算测试

- 月范围只统计所选自然月。
- 季范围只统计自然季度内的月份。
- 年范围统计自然年。
- 趋势图只纳入已确认收入和已确认支出。
- 待确认金额只进入 `待确认` 卡，不进入趋势图。
- 结余允许为负数。

### UI 冒烟测试

- 主窗口启动后仍默认打开看板。
- `月 / 季 / 年` 切换存在。
- 切换粒度后指标卡刷新。
- 年模式下可以看到按月趋势区域。
- 现有账户、提醒、流水摘要区域仍可显示。

### 回归验证

- `PYTHONPATH=src QT_QPA_PLATFORM=offscreen python3 -m pytest tests -q`
- 离屏启动应用，确认看板可构造且无崩溃。

## 非目标

本轮不做：

- 独立年度看板页面。
- 年度预算体系。
- 历史账户余额回溯。
- 分类占比图。
- 复杂 tooltip 和图表交互。
- 将待确认金额合并进正式趋势。
