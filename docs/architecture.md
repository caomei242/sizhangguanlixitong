# 草莓私帐管理系统架构说明

## 项目定位

草莓私帐管理系统是本地优先的 Mac 桌面应用，用来管理个人私帐、私人账户、预算计划、流水记录、充值续费提醒和账单识别。系统只处理个人私帐，不处理店铺经营账、公帐或副业经营财务。

## 技术栈

- Python 3.9+
- PySide6 桌面界面
- SQLite 本地数据库
- macOS Keychain 保存 MiniMax API Key
- pytest 做口径测试、仓储测试和 UI 冒烟测试

## 分层结构

- `src/private_ledger/app.py`：应用入口，创建 `QApplication`、字体、图标和主窗口。
- `src/private_ledger/ui/`：界面层，包含主窗口、页面、主题和通用组件。
- `src/private_ledger/domain/`：口径层，包含账户余额、预算对比、看板趋势、提醒计算等纯函数。
- `src/private_ledger/storage/`：SQLite schema 与仓储读写，不使用 ORM。
- `src/private_ledger/services/`：MiniMax 识别、Obsidian 同步、Keychain 等外部适配。
- `tests/`：计算口径、仓储与 UI 冒烟测试。

## 数据存储

默认数据库路径：

```text
~/Library/Application Support/草莓私帐管理系统/private-ledger.db
```

核心表：

- `accounts`：私人账户。
- `balance_snapshots`：账户余额快照。
- `transactions`：收入、支出、转账、充值、退款。
- `monthly_budgets`：月预算说明与兼容字段。
- `budget_lines`：预算项，支持生效开始月份和结束月份。
- `reminder_items`：阈值提醒与日期提醒。
- `app_settings`：本地设置。
- `import_batches`：识别批次与结构化结果。

`schema_info.version` 当前为 `3`。旧预算项在迁移时会补齐生效月份，默认只在原预算月份生效，避免历史预算扩散。

## 统计口径

- 正式收入、支出、结余只统计 `status = 已确认` 的流水。
- 待确认流水单独统计，不进入正式预算消耗。
- `支出` 进入消费与预算消耗。
- `退款` 冲减支出。
- `转账`、`充值` 不计入消费预算。
- 账户余额使用 `最后一条已确认余额快照 + 之后已确认流水净变化`。
- 储蓄预算视觉上单独分组，计算可支配结余时按支出处理。

## 预算匹配别名

预算工作台在统计时支持“显示名称”和“实际流水名称”分离，避免同一项目因为简称、全称或临时写法不同被拆成两行。

- 收入侧和支出侧的别名规则分开处理，避免 `其他收入` 和未来可能出现的 `其他支出` 混在一起。
- 别名归并只影响预算对比和统计，不会覆盖原始流水名称、来源备注或同步路径。
- 当前已经落地的典型口径：
  - `公积金收入` -> `房租补贴`
  - `替尔泊肽` -> `提尔`
  - `佛山税务`、`税务` -> `税务相关`
  - 收入侧 `其他` -> `其他收入`

## 看板范围

主窗口顶部范围选择支持：

- `日`：按所选月份展示每日趋势。
- `月`：按所选月份展示月度口径。
- `季`：按自然季度展示 3 个月趋势。
- `年`：按自然年展示 12 个月趋势。

日趋势会单独显示待确认金额线，帮助区分“没有数据”和“已有数据但未确认”。待确认线不改变正式收入、支出和结余口径。

## 预算工作台

当月预算工作台主分组：

- `长期收入`
- `当期收入`
- `长期支出`
- `当期支出`
- `储蓄`

表内类型显示名：

- `收入`：收入预算项。
- `单独支出`：单独盯的一笔项目型支出，底层仍保存为 `支出`。
- `固定支出`：月月都会来的固定开销。
- `分类支出`：按标签归类的一组零碎支出，底层仍保存为 `分类预算`。
- `储蓄`：视觉上独立展示，底层仍保存为 `储蓄计划`。

预算项常用字段可以在主表中直接编辑：

- 预算项
- 类型
- 标签
- 生效方式
- 开始月份
- 结束月份
- 计划金额

生效方式口径：

- `仅当前月`：只在所选月份生效。
- `每月持续`：从开始月份起长期生效，结束月份为空。
- `指定月份范围`：从开始月份到结束月份之间生效。

勾选 `联动同名项目` 后，表内编辑会同步处理其它月份同名或同标签预算项。默认关闭，避免误改历史预算。

## 流水确认

流水记录页支持单条编辑和批量确认：

- 右侧单条 `确认状态` 下拉修改后会即时保存。
- 表格第一列可勾选多条流水，再用批量状态操作统一改为 `已确认` 或 `待确认`。
- 状态变更后会刷新看板、预算和流水列表。

## 外部适配

### MiniMax

- API Key 保存到 macOS Keychain。
- 默认 API Host：`https://api.minimaxi.com/v1`
- 默认模型：`MiniMax-M2.7`
- 识别流程：OCR MCP `understand_image` 识别图片，再由 MiniMax 模型结构化为草稿。

### Obsidian

命令行入口：

```bash
PYTHONPATH=src python3 -m private_ledger.sync_obsidian --obsidian-root "<Obsidian 财务目录>" --month 2026-04
```

同步导入的数据以本地 SQLite 为准。开发日志不记录真实私帐明细。
